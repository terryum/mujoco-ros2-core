# Repository instructions

- Keep this repository robot-neutral and safe to publish.
- Do not add vendor robot assets, hardware credentials, private calibration,
  datasets, checkpoints, internal endpoints, or absolute user paths.
- Examples and tests must use synthetic models or redistributable public assets.
- ROS 2 imports must remain optional so the core test suite runs without ROS 2.
- Preserve backward compatibility for the exported backend, trajectory, and
  validation interfaces after a tagged release.
- Use `terryum` and `terry.t.um@gmail.com` for GitHub and commits.
